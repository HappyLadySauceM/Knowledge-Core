# Knowledge Core UI

Next.js frontend for the public knowledge blog and authenticated content administration.

```powershell
pnpm install
pnpm dev
```

The Go API is expected at `KNOWLEDGE_CORE_API_ORIGIN` (default `http://127.0.0.1:8080`).

Validation commands:

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
