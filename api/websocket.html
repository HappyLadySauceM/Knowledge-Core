Knowledge Core Collaboration WebSocket

Collaboration 为单个文档提供基于 Yjs 的二进制实时协作通道。连接前必须由 Gateway 创建短期、单次使用的 session ticket。

连接流程

  1. 调用 Gateway 的协作 session API。
  2. 把返回的 document ID 和一次性 ticket 放入 WebSocket URL 与 Sec-WebSocket-Protocol。
  3. 使用 knowledge-core-yjs-v1 和二进制 y-sync/awareness 帧。

握手约束

路径为 /v1/documents/{document_id}；document ID 必须是 UUIDv7，Origin 必须精确匹配允许列表。ticket 只能使用一次并在短期内过期。

关闭码

代码原因说明
4400invalid-protocol子协议、帧格式或协作更新不合法。
4401session-expiredsession ticket 已过期、已使用或关联会话已失效。
4403forbidden用户没有文档访问权限，或权限在连接期间被撤销。
4409document-invalidated文档已删除、失效或不再允许协作。
